## 核实结论

AI-Helper 确有 `bridge.rs` / `protocol.rs` / `config.rs`，而不只是 README 宣传；但它是综合开发工具管理器，不是原项目的直接升级包。

值得参考：Rust/Tauri 模块分层、显式的目的地址凭据策略、官方请求允许列表、协议适配边界、图片下载的大小与地址校验。

没有照搬：某些流式路径先完整读取再解析（不能提供真正实时输出）、工具调用 ID 不一致、按模型名猜测协议、与网关无关的账户管理/登录功能。原项目已有多提供商模型管理，参考项目并非在这方面天然更完整。

本重构已实现 Chat Completions/Ollama 转换；没有把参考项目的 Responses、Anthropic、图片生成或 MCP 名称直接写成已实现能力。真实 Accio/Windows 兼容性和性能必须另行实测。
